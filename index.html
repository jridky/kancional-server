Kancionál Server

Systém pro zobrazování čísel písní v kostele pomocí Raspberry Pi a mobilní aplikace

O projektu

Kancionál Server je řešení pro kostely, které umožňuje centrální nastavování a zobrazování čísel písní všem přítomným. Systém se skládá ze serveru běžícího na Raspberry Pi, jednoho či více číselníků (monitorů/televizí) a mobilní aplikace pro ovládání.

Varhaník nebo jiný pověřený člověk prostřednictvím aplikace na svém telefonu nastaví čísla písní a ta se okamžitě zobrazí na všech připojených číselnicích v kostele i na zařízeních věřících.

Druhy zařízení

Projekt nabízí několik variant nasazení podle potřeb konkrétního kostela:

Server

Samostatný server bez displeje. Slouží jako centrální bod, ke kterému se připojují číselníky a mobilní aplikace.

Číselník

Raspberry Pi s připojeným monitorem nebo televizí. Zobrazuje čísla písní. Vyžaduje server v síti.

Kombinace

Server a číselník dohromady na jednom zařízení. Ideální pro menší kostely s jedním displejem.

Číselník Dual Screen

Číselník na dvou monitorech/televizích současně. Vyžaduje server v síti. experimentální

Kombinace Dual Screen

Server s číselníkem na dvou monitorech/televizích současně. experimentální

TV Overlay

Overlay čísla písně přes živý obraz z kamery pro televizní obrazovky.

Co je potřeba

  • Raspberry Pi s operačním systémem Raspberry Pi OS (Bullseye, Bookworm nebo Trixie)
  • Wi-Fi síť pokrývající prostor kostela, k níž se připojí server, číselníky i mobilní zařízení
  • Monitor nebo televize s HDMI vstupem pro zobrazení čísel (pro varianty s číselníkem)
  • Mobilní aplikace Kancionál-Server pro Android

Wi-Fi síť

Pro správné fungování je zapotřebí mít v kostele veřejnou Wi-Fi síť, na kterou se budou moci varhaníci a případně i návštěvníci se svými zařízeními připojit.

Při výběru Wi-Fi zařízení je důležité zohlednit dva faktory: pokrytí celého prostoru kostela a počet současně připojených zařízení. Klasické Wi-Fi routery dokáží současně obsloužit pouze 8 až 16 zařízení. Pro větší kostely doporučujeme zařízení Ubiquiti od společnosti UniFi, která jsou schopná pokrýt velké prostory a obsloužit 250+ zařízení současně.

Instalace

Instalace je jednoduchá. Stačí zkopírovat příslušnou složku na cílové Raspberry Pi a spustit instalační skript: 

sudo ./install.sh

Skript automaticky nainstaluje potřebné balíčky, nakonfiguruje služby a nastaví grafické prostředí (Wayland na novějších systémech, X11 na starších).

Během instalace se skript zeptá, zda bude k zařízení připojena televize nebo monitor. Při volbě televize se nainstaluje podpora pro HDMI-CEC, která umožňuje automatické zapínání a vypínání televize.

Podporované systémy

  • Raspberry Pi OS Bullseye a starší (X11)
  • Raspberry Pi OS Bookworm (Wayland i X11)
  • Raspberry Pi OS Trixie (Wayland i X11)

HDMI-CEC

Pokud je k Raspberry Pi připojena televize s podporou HDMI-CEC, číselník dokáže televizi automaticky zapínat a vypínat. CEC je nutné povolit v nastavení televize:

  • Samsung: Anynet+
  • LG: SimpLink
  • Sony: Bravia Sync
  • Philips: EasyLink
